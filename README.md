# 💰 SubKiller - Subscription Tracker

**SubKiller** is a premium, 100% offline Android app that helps you track your monthly and yearly subscriptions (Netflix, Spotify, Gym, etc.), see your total monthly cost, and get reminders before you are charged.

## ✨ Features
- 📊 **Total Monthly/Yearly Cost:** See exactly how much you spend in one glance.
- 💵 **Multi-Currency Support:** Choose between ₹ INR, $ USD, £ GBP, € EUR, or ¥ JPY.
- 🛑 **Pause Subscriptions:** Pause a subscription for a month without deleting it.
- 🎁 **Free Trial Tracker:** Get alerts before a free trial ends so you don't get charged.
- 🔔 **Payment Reminders:** Receive notifications 2 days before a payment is due.
- 🌙 **Premium Dark Mode:** A sleek, neon-accented Material 3 dark theme.
- 🔒 **100% Offline & Private:** No account required. No bank access. All data stays on your device.

## 🚀 Installation
You can install SubKiller directly on your Android device.

1. Go to the **[Releases](https://github.com/CartonIQ/SubKiller/releases)** page.
2. Download the latest `SubKiller.apk` file.
3. Open the file on your phone and tap **Install** (you may need to allow "Install from unknown sources").

## 🛠️ Built With
- **Language:** Kotlin
- **UI:** Material 3, XML Layouts, ViewBinding
- **Architecture:** MVVM, Navigation Component
- **Local Database:** Room DB
- **Background Tasks:** WorkManager (for reminders)
- **Monetization:** Google AdMob
